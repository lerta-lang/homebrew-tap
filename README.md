# Homebrew tap for Lerta

The [Homebrew](https://brew.sh/) formula of [Lerta](https://lerta.org/), for macOS and Linux:

```
brew install lerta-lang/tap/lerta
```

It installs the compiler of [the latest release](https://github.com/lerta-lang/lerta/releases). The compiler builds programs with clang: [Tools](https://github.com/lerta-lang/lerta/blob/main/docs/reference/compiler.md#tools) lists what it needs on each system.
